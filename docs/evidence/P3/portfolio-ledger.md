# 당일 청산 가상원장 합성 검증

2026-11-13, 사용자의 “다음진행해”에 따라 [포트폴리오 계약](../../plans/intraday-portfolio-v1.md)의 원장 단계를 구현했다. 입력된 합성 체결의 현금·미결제금·보유 평가액을 합산한다. 실제 종목의 포트폴리오 수익률·미래 검증·P5 운용은 아직 NOT_RUN이다.

예제는 가상자금1,000만원, 원화500만원과 달러5,000달러, 환율1,000원에서 시작한다. 국내 주식을10만원에24주 매수하고10만1천원에 전량 매도한다. 매수·매도 비용은 각각0.1%다. 매수 후 NAV는9,997,600원, 매도 후10,019,176원, 전체자금 수익률은0.19176%다. 이는 산술 검증용으로 만든 가격이며 관측 수익률이 아니다.

매도 직후 원화 사용가능 현금은2,597,600원, 미결제금은2,421,576원이다. 미결제금은 NAV에 포함하지만 다시 매수하는 데 쓰지 않는다. 입력된 정산시각에 현금으로 이동하며 NAV는 바뀌지 않는다. 예제의 정산시각도 합성이며 실제 시장 결제일을 뜻하지 않는다.

## 구현 경계

`src/gon_stock/portfolio.py:replay_ledger`는 v1 네 종목의 정수 수량을 계산한다. 종목25%·합계 매수금액50%·평가액60%·거래당 계획손실0.5%·합산 일일 위험1%와 통화별 결제 현금을 함께 제한한다. 손절가는 입력 매수가의99%이며 입력 매수/매도 비용률을 포함한다. 보유 평가액에서 손절 후 예상 수령액까지의 차이를 잔여 위험으로 계산한다. 이미 NAV에 반영된 매수비용을 다시 잔여 위험에 더하지 않는다.

동시2종목·반대 시장 미청산·30분 이상 보유 중 추가 진입을 막는다. 손실중단은 일일1%·누적5%이며 관측 후 회복돼도 각각 해당 위험관리일/전체 재생 동안 유지한다. 일일 손실은 `max(일일 시작 NAV - 현재 NAV, 0)`이고 이익이 있어도 신규 위험예산은 초기자금1%를 넘지 않는다. 환율 변화는 달러현금과 미결제금·미국 보유 평가액 모두에 반영한다.

시각은 시간대가 있는 값만 받고 역행을 거부한다. 매 이벤트에 현재 FX와 모든 보유 종목의 평가가격을 요구한다. 초기자금/초기환율로 현금을 배정하고 첫 이벤트부터 평가한다. 첫 이벤트 환율이 초기환율과 다르면 그 차이도 첫 위험관리일의 손익과 손실중단에 반영한다. 이후 위험관리일을 넘을 때는 매일07:00 KST의 `mark`가 있어야 하며, 경계를 건너뛰면 실패한다. 경계 NAV가 다음 일일 수익률의 기준이다. 입력 관측 사이의 한도 위반은 판정할 수 없다.

`buy`는 `gates=true`인 합성 입력에만 허용한다. 이것은 실제 호가·일정·신호·품질을 검증한 증거가 아니다. 거래 시각/휴장/실적 일정 검증, 신호 생성, 미체결 주문 예약, 부분 체결, 자동 손절·마감 청산, 실제 결제일 계산은 아직 연결하지 않았다. 가격은 합성 체결가격과 평가가격이 같아야 한다. 비용률은 입력에서 한 번 적용하며 이미 비용이 반영된 가격과 중복 계산하면 안 된다.

실시간 실행기 대신 순서가 고정된 합성 체결 재생을 선택했다. 원장 산술을 검증하면서 불완전한 시세·정산 가정이 주문 경로로 이어지는 것을 방지하기 위해서다. 입력 끝의 보유는 `unclosed`로 남기며 임의로 종가 청산하거나 성공한 당일 청산으로 표시하지 않는다. 현재 CLI는 `synthetic-ledger-v1`만 허용한다.

## 재현과 다음 행동

비공개 입력은 `kind`, 십진 문자열 `capital`/`initial_fx`, `events` 배열이다. 모든 이벤트에 `at`, `action`, `fx`, `marks`가 필요하다. `buy`에는 `symbol`, `price`, `buy_rate`, `sell_rate`, `gates`를, `sell`에는 `symbol`, `price`, `settlement_at`을 추가한다. 비용률0.001은0.1%다. 출력은 정규화 JSON 입력해시(파일 바이트 해시가 아님)와 이벤트별 NAV·수익률·통화별 현금/미결제금·수량·진입 거절 사유를 담는다.

```sh
uv run pytest -q tests/test_portfolio_ledger.py
uv run python -m gon_stock.ledger_cli \
  --input .private/ledger-20261113/input.json \
  --output .private/ledger-20261113/replayed.json
```

기존 출력은 덮어쓰지 않는다. 예제 원본은 `.private/ledger-20261113/input.json`, 실행 결과는 같은 디렉터리의 `output.json`에 보관했다. 전용25개 검사에서 비용/NAV 항등식·정산 전 재사용 차단·국내 손실 이후 미국 수량 축소·FX 손실중단·날짜 경계·입력검사·미청산 보존·CLI 재실행 덮어쓰기 차단을 확인했다.

다음은 선택 종목 분봉의 품질과 실제 비용/결제 조건을 확인하고, 신호/체결 재생과 기준ETF·현금 비교를 원장에 연결하는 것이다. 기존 과거 구간은 탐색용이며 새 표본외 결과로 바꾸지 않는다. P3 실제 성과 수용/P5 보류, 기존 수집 종료 한도11/19 09:00 KST는 유지한다. 새 자동 실행 예약은 없다.

추가 점검: 달러 보유/미결제금 FX 재평가, 거래당0.5% 계획손실 상한, 30분 이상·중복 보유·잘못된 청산/정산·이틀 경계 누락과 CLI 비정상 형식/극단 숫자를 검사했다. 네 종목의 매매 현금흐름을 별도 수식으로 계산해 NAV와 대조했다. 비종결 환율은 Decimal 정밀도에 따른 미세 오차를 허용하며 원화1e-15 미만을 확인했다. `remaining_risk`는 산술 잔여량이며 중단 상태에서는 양수여도 진입할 수 없다. 행별 원본 정보는 순서대로 입력과 대조한다.

출력 디렉터리는 기존 `private_path`로 접근권한700을 적용하고 결과 파일은600으로 제한한다. 쓰기 도중 I/O 실패 시 부분 파일이 남을 수 있어 성공 출력이 없으면 내용을 사용하지 않고 새 출력 경로로 재실행한다. 문체검사는 기존 표준 파일 부재로 NOT_RUN이다.
