# P3 평가 계약 v1

2026-11-12. 실제 성과 평가 전에 기준과 실패 조건을 고정한다.
P2 수용 근거는 [이슈 #6](https://github.com/krdn/gon-stock/issues/6#issuecomment-6811449518)이다.
현재 실제 표본 31행은 성과 평가에 부족하다. 합성 테스트와 실전 성과를 구분한다.

## 첫 기준 전략

`relative-volume-intraday-v1`은 장중 기준선이다. 같은 시장의 사전 지정 종목군과 기준 ETF를 사용한다.
현재 관심 목록을 과거 종목군으로 재사용하지 않는다. 야간 보유 전략은 아직 평가하지 않는다.

- 같은 시점의 완료 1분봉 21개로 20분 수익률을 계산한다. 종목 수익률에서 기준 ETF 수익률을 뺀다.
- 상대 수익률이 0.1% 이상, 최신 거래량이 앞선 20분 평균의 1.5배 이상이면 후보로 기록한다.
- 시세를 받은 다음 분의 시가에 진입을 가정한다. 이미 지난 시가로 체결시키지 않는다.
- 동시에 한 포지션만 평가한다. 동시 후보는 종목 키 순으로 결정하며 미래 성과로 고르지 않는다.
- 진입가 기준 손절 1%, 목표 1.5%, 최대 30분 또는 정규장 종료 중 먼저 오는 시점에 종료한다.
- 한 봉에서 손절·목표가 모두 닿으면 손절을 먼저 적용한다. 불리한 갭은 시가로 반영한다.
- 단일 거래의 수익률을 평가한다. 실제 계좌 주문·수량·환율 원장·포트폴리오 위험 엔진이 아니다.

숫자는 최적화 결과나 매매 추천이 아닌 최초 연구 매개변수다. 평가 결과를 본 뒤 같은 test 구간에 맞춰 바꾸지 않는다.
정규장 밖·미확정·미완료·미래 시세는 제외한다. 입력의 수신시각을 과거로 바꾸지 않는다.
분봉 라벨·공급 범위·정정/기업행동·달력·시계 검증이 없는 실제 자료는 성과 수용 근거로 쓰지 않는다.
기업행동 또는 명시적 정정이 섞인 구간은 이번 엔진에서 거부한다. 임의 수정계수를 소급 적용하지 않는다.

## 평가와 비용

학습→확률 보정→최종 평가 날짜를 데이터 manifest에 고정한다. 구간 사이에는 2거래일을 비운다.
구간 경계를 가로지르는 거래는 제거한다. 최종 평가 구간으로 전략·확률을 맞추지 않는다.
20분 상대 수익률 0.5%를 경계로 두 그룹을 고정한다. 학습 구간의 경험 확률을 만들고 별도 보정 구간으로 확률을 보정한다.
각 그룹 학습·보정 거래가 30건 미만이면 해당 확률은 표시하지 않는다.

수수료·매도세금·스프레드·슬리피지·환전비용은 bps 입력으로 각각 반영한다. 1bps는 0.01%다.
실제 비용 확인 전 테스트용 수치를 운영 비용으로 쓰지 않는다. 기본·2배 비용 스트레스를 모두 보고한다.
거래 수, 순기대값, 승률 구간, Brier score, 그룹별 예측/관측 빈도, 단위 수익률 drawdown을 기록한다.
Wilson 승률 구간은 거래 독립성 가정의 참고치다. 기대값은 5거래일 블록 bootstrap 1,000회(seed=20261112) 구간도 보고한다.
불확실성 계산도 미래 분포 변화나 수익을 보장하지 않는다.

## 후보 판정

- 최종 평가에 최소 100거래·20거래일이 있어야 한다. 표본이 부족하면 평가를 보류한다.
- 기본·2배 비용의 평균 순수익과 기본 비용 bootstrap 95% 구간 하한이 양수여야 한다.
- 보정 확률의 Brier score가 학습 전체 승률을 쓰는 상수 기준보다 나쁘면 탈락한다.
- 그룹별 보정 오차·표본 수·승률 구간을 함께 제시한다. Brier만으로 보정 성공을 단정하지 않는다.
- 합성·모의·현재 시점에 조회한 역사 자료만으로 실제 성과를 수용하지 않는다. 실제 시점 자료와 비용·품질 근거가 필요하다.
- 보류·탈락도 결과로 저장한다. P3 전체 수용 전 P4로 승격하지 않는다.

## 근거

- [시계열 평가](https://otexts.com/fpptr/tscv.html): 예측 시점 이전 자료만 학습에 사용.
- [확률 보정](https://scikit-learn.org/stable/modules/calibration.html): 학습과 보정 자료 분리, 적절한 평가 점수와 신뢰도 곡선 구분.
- [NIST 비율 구간](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/propconf.htm): Wilson 구간 계산과 제한.

KIS 국내 역사 분봉은 [공식 샘플](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/domestic_stock/inquire_time_dailychartprice/inquire_time_dailychartprice.py)에 최대 1년·호출당 120건으로 설명된다.
지금 받은 역사 자료의 received_at은 지금이다. 과거 당시 알려졌던 자료나 정정 이력을 자동으로 증명하지 않는다.
