## 후보 `opening-range-relative-v1`

종목은 기존000660·005380·NVDA·AMZN, 기준은069500·SPY로 고정한다. 정규장·매수 전용이며 [포트폴리오 v1](intraday-portfolio-v1.md)의 자금·동시보유·손실한도를 유지한다. 아래 숫자는 최적화 결과가 아닌 사전 연구 매개변수다.

1. 공식 정규장 개시부터 첫30분의 완료1분봉 고가 최댓값 H를 고정한다. 수능일 등 예정된 개장 변경은 공식 달력 개시를 따른다. 예정 밖 개장 지연·중단·자료 부재로 범위를 온전히 만들 수 없으면 해당 종목/세션은 거래하지 않고 사유를 기록한다. 시간을 뒤로 밀어 범위를 재구성하지 않는다.
2. 개장30분 이후부터120분 미만의 완료봉에서 최초로 종가가 H보다 높아지면 돌파 후보로 삼는다. 직전 완료봉 종가는 H 이하여야 한다. 직전 봉이 없으면 해당 세션을 품질 실패로 기록한다. 같은 시점 기준ETF 종가는 당일 첫봉 시가보다 높아야 한다. 종목의 당일 시가 대비 수익률은 ETF보다0.1%p 이상 높아야 한다. 비교 자료가 없으면 진입하지 않는다.

## 기간과 평가 잠금

가장 빠른 시작 후보는2026-11-16이며 자동 시작일이 아니다. 데이터·비용 조건과 구현 검사를 마치고, 첫 평가용 자료 수집 전에 시장별 거래일 전체 목록·코드 SHA·manifest 형식과 수집 설정·요율 적용일을 고정한다. 수집된 원본의 세션별 해시는 추가 전용으로 기록한다. 늦어지면 결과를 보기 전에 시작일과 이유를 기록한다. 기존05~11월 자료와 11월13일 진행 중 세션은 새 표본으로 사용하지 않는다.

이번 회차는 시장별 학습52 → 제외2 → 보정24 → 제외2 → 최종평가40의120세션을 선택한다. 판정 단위는 **4종목 통합 포트폴리오 하나**다. 시장별 결과는 보조 보고이며 별도로 합격시키지 않는다. 하루1회 제한으로 보정은 최대96거래, 최종평가는 최대160거래다. 보정의 두 그룹 각각30거래와 최종100거래에는 이론상 기회의62.5% 이상이 필요하다. 신호·자금 거절로 더 줄 수 있으므로 **표본 부족 보류 가능성이 높은 첫 회차**다. 부족하면 기준을 낮추거나 날짜를 사후 추가하지 않는다. 더 긴 검증이 필요하면 실패/보류를 남기고 별도 사전등록 회차로 시작한다.

두 시장을 같은 실제 시각 경계로 진행한다. 학습은 공통 시작 위험관리일07:00 KST 이후 시장별 첫52세션을 쓰고, 두 시장 중 늦은 마지막 청산 뒤 각 시장의 완전한2세션을 모두 비운다. 그 이후 첫07:00 KST부터 보정을 시작해 시장별 첫24세션을 쓴다. 같은 방식으로 두 시장 보정 종료와2세션 제외가 모두 끝난 다음07:00 KST부터 평가한다. 시장별 첫40세션의 마지막 청산 중 늦은 시각 뒤 첫07:00 KST에서 평가를 종료한다. 한 시장이 할당 세션을 먼저 마치면 다음 공통 단계까지 거래하지 않는다. 이 대기일 때문에 실제 경과기간은120세션보다 길 수 있다. 모든 보정 거래의 청산은 모든 평가 신호보다 앞서야 하며 위반하면 평가를 거부한다.

공식 달력으로 날짜/UTC 경계와 대기일을 수집 전에 확정한다. 품질 불량일을 다른 날짜로 대체하지 않는다. 휴일·거래 불가능·대기일도 원장 시간축에 남기며 품질 실패는 평가를 보류한다. 평가 시작에 원장·일일/누적 손실한도를 초기1,000만원·원화/달러50:50·보유/미결제0으로 새로 설정한다. 학습/보정 손익과 위험 상태를 이월하지 않는다. 실제 시작환율과 이후 시점별 FX를 쓰며 평가 종료까지 전체 현금/NAV를 추적한다.

학습에서는 전략 임계값을 조정하지 않는다. 신호 완료봉 시점 상대수익률0.5%p 미만/이상의 두 그룹별 기본 비용 후 승리 확률을 산출한다. 별도 보정 구간에서 경험 확률을 보정하며 한미 거래를 통합하되 학습과 보정은 분리한다. 각 그룹의 학습 구간과 보정 구간 각각30거래 미만이면 표시하지 않는다. 확률은 진입 필터로 사용하지 않는다. test 최소100완료거래·20거래일, 기본/2배 비용 순기대값과95% 블록 bootstrap 하한, Brier/보정오차는 [기존 P3 기준](p3-evaluation.md)을 유지한다. 그룹 표본 부족이면 수용 보류이며 기준을 낮추거나 기간을 사후 연장하지 않는다.

수용 판정 대상은 새 후보 하나이며 기존 전략은 참조다. 기존 전략과 새 후보를 같은 새 기간·가용 자료·시장별 비용·자금 제약으로 비교한다. 현금100%·069500 또는 SPY 각50%/현금 기준선도 기록한다. 후보의 개선을 기존 과거 수익률과 직접 비교해 주장하지 않는다. 사전 통화 배정 뒤 달러 현금의 환율 변동을 반영하고, 고정환율 연구 결과는 실제 성과와 분리한다. 최종표에는 전체NAV·최대낙폭·거래 수·거절 사유·미청산·시장별 결과를 모두 남긴다.
