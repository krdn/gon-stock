# 비용과 매도대금 사용 가능 시점

2026-11-13 조회. **공식 일반요율은 확인했지만 계좌별 실제 비용과 자금 가용시각은 미확인이다.** 기존 왕복25bps·결제 잠금 가정으로 실제 계좌 성과를 단정할 수 없다. [다음 검증 계획](../plans/p3-next-validation.md)에서 이 조건을 분리한다.

사용자는 계좌 요율을 모른다고 답하고 “공식 일반요율과 미확인 조건으로 진행”을 선택했다. 우대율을 추정하지 않으며 국내 계좌 유형도 임의로 뱅키스로 확정하지 않는다.

## 일반요율과 계좌 적용

| 대상 | 공식 공시 기준 | 연구에 주는 의미 |
|---|---|---|
| 국내 KRX 일반 주식 | 뱅키스 온라인 편도0.0140527%, 영업점 개설 온라인 편도0.147% | 계좌 종류와 API 적용 여부 확인 필요 |
| 국내 KOSPI 매도 | 증권거래세0.05% + 농특세0.15% = 0.20% | SK하이닉스·현대차에 매도 방향으로만 반영 |
| 미국 일반 온라인 | 편도0.25%, 매도 SEC Fee0.00206% | 동일 가격 왕복 수수료·SEC Fee만50.206bps |

국내 근거는 한국투자증권 [주식거래 설명서 10·11절](https://file.truefriend.com/Storage/customer/guide/regards/stock_guide.html)이다. 미국은 [일반 해외주식 요율표](https://m.truefriend.com/main/bond/research/_static/TF03ca050000.jsp)이며 미니스탁 행을 사용하지 않았다. SEC의 [2026-2 공지](https://www.sec.gov/rules-regulations/fee-rate-advisories/2026-2)는 4월4일부터 매도100만달러당20.60달러를 명시한다. 실행 시점의 변경 여부는 다시 확인한다. 유관기관 비용의 고객 전가·최소액·반올림·우대 적용은 별도 확인 대상이다.

예를 들어250만원을 같은 가격에 매수·매도하면 뱅키스 일반요율·KOSPI 세금의 산술 비용은5,702.635원(22.81054bps)이다. 영업점 온라인이면12,350원(49.4bps)이다. 미국2,000달러 왕복은10.0412달러다. 모두 호가 차이·슬리피지·환전과 세부 절사 전 계산이다. 기존25bps는 국내에서도 총비용을 보장하지 않으며 미국 일반요율에는 부족하다. 이 산술은 기존 수익률을 수정한 재생 결과가 아니다.

실제 비용 입력에는 계좌별 매수/매도 수수료, 세금, 최소액·절사, API 우대 만료일, 환전 스프레드와 적용일이 필요하다. 개인정보·계좌번호·인증값 없이 요율과 조건만 확인한다. 호가와 체결 자료가 없으면 스프레드·슬리피지는 실측값으로 표시하지 않는다. 해외 양도소득세처럼 연간 개인별 세금은 별도이며 이번 거래비용 산술에 포함하지 않는다.

## 결제와 재사용

국내 설명서는 T+2 결제를 명시한다. 미국 현지 주식 결제의 [T+1 제도](https://www.investor.gov/introduction-investing/investing-basics/glossary/settling-securities-transactions-t1)는 한국 계좌의 입금·환전·출금 시각과 같다는 뜻이 아니다.

한국투자증권 [외화증권 설명서 매매증거금 절](https://file.koreainvestment.com/Storage/customer/guide/regards/service_03_1%283%29.htm)은 미국 등 동일 시장에서 매도 제비용을 뺀 대금을 입금 전 매수증거금으로 사용할 수 있다고 설명한다. 통합증거금은 별도 신청 조건이다. [결제일 안내 유의사항](https://m.truefriend.com/main/bond/research/_static/TF03ca050002.jsp)은 통상15시 이후 입금과 지연 가능성을 설명한다.

따라서 기존 재생의 일률적인 `T+2 지역 거래일 + 07:00 KST` 해제는 확인된 실계좌 규칙이 아니다. 잠금으로 거래가 줄어도 수익률이 항상 보수적으로 추정되는 것은 아니다. 기존 결과를 보존하고 해당 가정을 명시한다. 미국 현금계좌의 일반 설명을 한국 증권사 계좌에 그대로 대입하지 않는다.

다음 원장에서는 결제된 현금, 미결제 채권, 해당 시장 재매수 가능액, 출금 가능액을 구분해야 한다. 재매수 가능액을 현금이나 순자산에 다시 더하면 이중 계산이다. 일반 약관만으로 개인 계좌의 재매수·재매도·API 주문가능액 일치를 PASS로 올리지 않는다. 미확인 시 신규 진입 차단, 미결제금의 NAV 포함, 시장간 대금 공유/차입/자동환전 금지를 유지한다. 계좌별 확인 전 기존 실행 규칙을 변경하지 않는다.

## 증거와 남은 확인

공식 본문을 읽고 비공개 원문을 보존했다. 아래는 11월13일 다운로드 바이트의 SHA-256이다.

- 국내 설명서: `4e601deb80de0d38f395bfd8a170003f5e238eb3e5d29ec900dee9ee94157c10`
- 미국 요율표: `faff392f231c540cb7e7a48e91346ca54292623f52a9f5d3751f575bfc22b726`
- 외화증권 설명서: `547c7dd05563352efe99eedcc4313e0472178aedf4ce583e67ca8c3bdc7819ca`
- 결제일 안내: `549e4f17e5d3512358383944a073a71c3906764007c5f3a18d53665664bf98aa`

SEC는 웹 조회로 내용을 확인했으나 로컬 원문 요청은403이었다. 오류 페이지 해시를 공문 해시로 사용하지 않는다. 계좌별 우대·재사용 조건, 국내 재매수 규칙, 한미 휴일과 입금시각, 실제 호가 비용은 아직 미확인이다. 실제 계좌 조회나 거래로 확인한 결과는 없다.
